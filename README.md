# NLP Tasks on Romanian

This repository contains code for several supervised and semi-supervised training strategies, namely:
- Supervised
    - plain model
    - curriculum learning
    - contrastive learning
    - mixture of experts
    - curriculum + contrastive learning
    - mixture of experts + curriculum learning
    - mixture of experts + contrastive learning
    - mixture of experts + curriculum + contrastive learning

- Semi-supervised (more specifically, self-training)
    - self-training + plain model
    - self-training + curriculum learning
    - self-training + contrastive learning
    - self-training + mixture of experts
    - self-training + mixture of experts + curriculum learning
    - self-training + mixture of experts + contrastive learning
    - self-training + curriculum + contrastive learning
    - self-training + mixture of experts + curriculum + contrastive learning

All of these algorithms are tested on named entity recognition (NER) and fake news detection on Romanian text.
